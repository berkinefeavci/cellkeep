# Cellkeep update bridge

Cellkeep is now **Healthy Battery**. Current source, issues, and releases: [berkinefeavci/healthy-battery](https://github.com/berkinefeavci/healthy-battery).

This repository only serves a compatibility release for installed Cellkeep 1.2.1 copies. Their built-in updater requires a release page under the original `cellkeep` address. Download the new app from [Healthy Battery releases](https://github.com/berkinefeavci/healthy-battery/releases/latest).

The compatibility DMG keeps the same signed app identity and preserves existing settings and history.
